# CodeBuddy Clone

A polished CodeBuddy-inspired product landing page and AI-product studio mockup built with React + Vite.

## Features

- Modern SaaS-style landing page
- Product overview and feature sections
- AI coding workspace mockup
- Pricing cards
- Responsive layout for desktop and mobile

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```
